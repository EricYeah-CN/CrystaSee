# CrystaSee 常见引文格式

基准元数据（所有格式共用）：

| 字段 | 值 |
|---|---|
| 作者 | Ye, Yang（引文中缩写为 Ye, Y.） |
| 年份 | 2026 |
| 标题 | CrystaSee: Interactive Crystal Structure Visualization and Analysis |
| 类型 | Computer software / 计算机软件 |
| 出版者 | Zenodo |
| **概念 DOI**（主用） | `10.5281/zenodo.24564477` |
| 版本 DOI（V1.13，精确复现用） | `10.5281/zenodo.24564478` |

以下均以**概念 DOI** 为主引用，指向所有版本的最新页。若论文结论依赖 V1.13 的具体行为，请把 DOI 换成版本 DOI，并在标题后加 `(Version v1.13)`。

## 精确复现 V1.13 时的引用（版本 DOI）

Zenodo 官方 “Cite as” 原文（APA）：

```
Ye, Y. (2026). CrystaSee: Interactive Crystal Structure Visualization and Analysis (Version v1.13) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.24564478
```

BibTeX（版本 DOI）：

```bibtex
@software{ye2026crystasee_v113,
  title        = {CrystaSee: Interactive Crystal Structure Visualization and Analysis (Version v1.13)},
  author       = {Ye, Yang},
  year         = {2026},
  publisher    = {Zenodo},
  version      = {v1.13},
  doi          = {10.5281/zenodo.24564478},
  url          = {https://doi.org/10.5281/zenodo.24564478}
}
```

**注意**：Zenodo 界面不直接提供概念 DOI 的 “Cite as”；上面的概念 DOI 版本是按官方引用格式去掉版本后缀、替换 DOI 构造的，属通行做法。
